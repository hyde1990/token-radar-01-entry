How the implied value is computed

One function scores every row, from the snapshot figures only. No protocol name is special-cased and no row is hand-picked. A protocol is called pre-token only when the snapshot records no token for it — no market cap, no CoinGecko id, no symbol. That is what the record proves; it does not prove a token will ever exist.

implied = TVL × category multiple × size multiplier × growth multiplier × maturity multiplier

  • Category multiple. The median market-cap-to-TVL ratio of live-token protocols in the same category, with at least 5 live observations; everything else uses the overall median 0.205. Lending 0.132, Yield 0.180, RWA 0.275, Dexs 0.342, Bridge 0.557, Basis Trading 0.60 (clamped from 0.654). All multiples are clamped to 0.08–0.60, so a single outlier protocol can never set a whole category's value.
  • Size multiplier. (50M ÷ TVL)^0.10, clamped to 0.70–1.30. Small protocols trade at far higher multiples of TVL than giants — the band medians fall from 0.414 at $5–50M to 0.131 at $50–500M, 0.032 at $500M–5B and 0.044 above $5B — but that fall is confounded by category mix, so only this mild dampener is claimed. Implied value still rises with TVL, as TVL^0.9.
  • Growth multiplier. 1 + 0.60 × clamp(7-day change, −40%, +60%) ÷ 100. The clamp is mandatory: one protocol grew +4,448% in a week, and an uncapped term would hand the board to it. Only 6 protocols exceed +60% and 1 falls below −60%.
  • Maturity multiplier. 0.70 + 0.30 × min(age in days, 1,095) ÷ 1,095. Long pre-token life is a durability signal — live-token protocols are far older (median 928 days) than pre-token ones (513 days) — but youth is already rewarded through growth, so maturity is a gentle premium, not a second reward for youth. Unknown age uses 365 days.
  • Board. Every pre-token protocol the watchlist rule allows once the $50M floor is lifted — 198 rows: the 40 watchlist protocols plus 158 early ones below the floor. Excluded: exchanges, bridges, liquid staking and restaking wrappers, versioned pools, wrapped or staked assets, and exchange-owned products.
