      How the implied value is computed

      One function scores every row, from the snapshot figures only. No protocol name is special-cased and no row is hand-picked. A protocol is pre-token only when the snapshot records no token for it — no market cap, no CoinGecko id, no symbol. That is what the record proves; it does not prove a token will ever exist.
